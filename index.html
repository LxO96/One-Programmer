Welcome to the Crem One Programmer

This is a pressure profile editor for the Crem One. It reads the machine's profile file, lets you reshape all five profiles by hand, and writes a new file you can load back onto the machine.

Reading the graph

Volume runs left to right across the profile's total millilitres. Pressure from 0 to 10 bar. The curve is the pressure the machine holds at each point of the shot.

The two zones

The shaded band on the left is pre-infusion — low pressure that wets the puck evenly before the actuall shot. The rest is extraction, where your pressure curve pulls the shot. You can change where the boundary sits under the ⚙ settings button.

Editing a curve

Click anywhere to add a point — double-click one to remove it
Drag a point to move it
Drag a handle to bend the curve — the two sides stretch independently

A selected point always shows both of its handles, even when one is pulled right in against the point.

Loading a file

Drop a .txt profile on the panel at the top left — it tells you what it loaded

Or press Select file to pick one, or just start from the profiles already loaded. All five profiles come from a single file, so loading one replaces the lot.

Exporting

When you're done, pick the file version your machine expects and hit Export. Nothing is saved between visits, so export anything you want to keep.
